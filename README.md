## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/BreakDown-CS/portfolio-cs-web.git

# Navigate to project directory
cd portfolio-cs-web

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Compile TypeScript & generate production bundle
npm run build

# Preview production build locally
npm run preview
```
